# Student Performance Management System

A Python-based command-line application for managing student records, validating student information, calculating grades, searching records, and viewing academic performance statistics.

This project was developed as part of my journey to improve my Python programming skills and build practical software projects.

## Features

* **Add Students:** Record student names, ages, departments, and scores.
* **Input Validation:** Validate student information and handle invalid inputs.
* **Automatic Grading:** Calculate grades based on students' scores.
* **View Students:** Display saved student records.
* **Search Students:** Find individual student records.
* **Performance Statistics:** View statistics about students' academic performance.
* **Data Persistence:** Store and retrieve student records using JSON.
* **Menu-Driven Interface:** Navigate the application through a command-line menu.

## Getting Started

### Prerequisites

Install Python from [python.org](https://www.python.org/downloads/).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/timothyakhimien-ctrl/student-performance-management-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd student-performance-management-system
   ```

3. Run the application:

   ```bash
   python student_performance.py
   ```
